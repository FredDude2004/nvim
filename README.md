# My Personal NeoVim Configuration

This is my personal neovim configuration with my chosen plugins and key-binds. 
It is heavily influenced by Kickstart.nvim with most of the keybindings and
configuration coming straight from kickstart as well as from TJ's [Advent of NeoVim](https://www.youtube.com/playlist?list=PLep05UYkc6wTyBe7kPjQFWVXTlhKeQejM)

I recently re-wrote the entire configuration when I upgraded to NeoVim 0.12.2
I practically copied the single file configuration from [The Rad Lectures Video](https://www.youtube.com/watch?v=lljs_7xB7Ps)

There are a ton of color-schemes installed as I am still playing around with 
some different themes and finding what I like.
